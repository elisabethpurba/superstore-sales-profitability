# Superstore Sales & Profitability Analysis

An analysis of Superstore sales data using **Microsoft Excel** to evaluate sales performance and profitability across sub-categories, time periods, regions, customer segments, and discounts.

## Objectives

This project aims to:
- Analyze sales and profit trends over time.
- Identify the best-performing regions and sub-categories.
- Analyze sales performance across customer segments.
- Evaluate profitability across different discount levels.
- Present analytical findings through an interactive dashboard.

## Dashboard

The dashboard covers the **2014–2017** period and includes the following key metrics:

| Metric | Value |
|---|---:|
| Total Sales | $2,297,200.86 |
| Total Profit | $286,397.02 |
| Total Transactions | 9,994 |
| Total Quantity | 37,873 |
| Average Discount | 15.62% |

## Key Insights

- **Phones** recorded the highest sales at **$330,007.05**.
- **Copiers** generated the highest profit at **$55,617.82**.
- **Tables** recorded a negative profit of **-$17,725.48**.
- Sales and profit performance varies across sub-categories, indicating that performance evaluation should not rely on sales alone.
- Sales distribution can be evaluated across regions, customer segments, and time periods.
